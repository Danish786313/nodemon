1. What is Big O?

Big O tells us how the amount of work an algorithm does grows when the input size increases.

O(1) — Constant work.
O(log n) — Work grows slowly as the input grows.
O(n) — Work grows linearly with the input.
O(n log n) — Common in efficient sorting algorithms.
O(n²) — Work can grow very quickly.
O(2ⁿ) — Work can grow exponentially.


Rule 1: Drop constants
Rule 2: Keep only the dominant term
Rule 3: Different inputs get different variables
Rule 4: Consider the worst case
Rule 5: Sequential steps add; nested steps multiply
